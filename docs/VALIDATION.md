## 실제 환경에서 남은 검증

- OpenAI/Claude 유료 외부 API는 실제 호출하지 않았습니다. Qwen3는 실제 Support와 선택 점검을 확인했지만, 다양한 프로젝트의 평가 품질·재현성·비용 비교는 별도 확인이 필요합니다.
- macOS/Linux 및 다양한 화면 크기에서의 검증은 수행하지 않았습니다. Windows에서 Python 서버와 브라우저 UI 동작을 확인했습니다.

이는 사용자 프롬프트의 실제 결과 품질을 검증했다는 뜻이 아닙니다. 평가 모델을 바꾸거나 기준을 변경하면 같은 연습 자료로 사람 평가와 비교해 기준을 보정하세요.
